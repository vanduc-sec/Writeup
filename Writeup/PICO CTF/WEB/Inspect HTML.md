# Inspect HTML

Bản chất & Ví dụ: - HTML source: HTML là cấu trúc gốc tạo trang web. Ví dụ <div>, <form>, <input> là các node giao diện.- View Source: Xem source giúp thấy nội dung trình duyệt tải về, kể cả comment.- Comment HTML: Comment không hiện trên giao diện nhưng vẫn nằm trong response. Ví dụ <!-- hidden note -->.
Hệ sinh thái kiến thức: - HTML source- View Source- DevTools Elements- Comment HTML
